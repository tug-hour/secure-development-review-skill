# IPA第1章の評価基準

対象はIPA『安全なウェブサイトの作り方』改訂第7版第4刷、第1章1.1〜1.11。公式[案内](https://www.ipa.go.jp/security/vuln/websecurity/about.html)が2021-03-31公開版と第1章の各節HTML抜粋を示している。2026-11-01に案内と全11節をリダイレクトなしで新規取得・読解した。旧スキル・旧採否・過去評価を利用していない。全47対策IDを、前提/代替/根本的解決と保険的対策の区別を保って独自に再構成した。

対象の具体的な入力・出力・認証等の疑問に関係する節を選び、条件・代替・根本/保険の違いを確かめる。全47対策の判定は要求しない。既存根拠は有効な範囲で使い、対策や検査の存在を安全保証にしない。

## 取得点と権利

各節冒頭に公式URL、取得日、取得HTMLのbytesとSHA-256を記録した。案内HTMLは236,577 bytes、SHA-256 `7634edcd258af357472df0319b7ae9d0b39b40bed8befcd02c4d17b60eed426e`。ライブHTMLの取得点を記録したもので、URLの不変性やPDF自体とのbyte一致を保証しない。PDFは今回は取得/同梱せず、IPA公式が第1章抜粋と指定するHTMLを入力にした。
