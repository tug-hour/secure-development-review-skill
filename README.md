# Secure Development Review — v0.3-rc.1

**別環境から取得して参照・検証するために公開した配布候補版です。CC BY-SA 4.0を採用しています。** 作者の標準運用は通常レビューで、スキルは未導入です。

本スキルは、変更に関係する安全条件を選び、必要な証拠を追うためのAI向け指示です。認証・認可、入力と処理境界、データ保護、状態と資源、依存・実行環境の5分野を扱います。AI支援で作成した統合原案であり、原典の公式翻訳や認証・監査サービスではありません。

## どんな場合に使うか

設計、コード、設定、依存更新、ビルド・配布経路について、明示的にセキュリティレビューを依頼する場合の参考原案です。対象と差分、期待する許可・データ・業務条件、関係する設定や既存検査結果を、提供可能な範囲で示してください。重要な仕様が不足する場合は、その論点を未確認として扱います。

通常の書式・品質確認だけに適用したり、全ガイドの全規則を毎回チェックしたりする使い方は想定していません。通常レビューに指示が足りている場合に、本スキルを追加する効果は確認できていません。

## 利用の仕方

以下は任意に導入する場合の説明です。作者の環境では導入を実施していません。

まずSKILL.mdと参照資料を読み、組織の規則や権限と整合するか確認してください。導入せずに文書を参考にすることもできます。Codexへ任意に導入する場合は、承認された配置先の例として、対象プロジェクトの`.agents/skills/secure-development-review/`にSKILL.mdとreferences/を一緒に配置します。既存の同名フォルダを上書きしないでください。導入後は明示呼出だけでなく、descriptionに合う依頼で選択される場合があります。通常レビューを標準に保つ作者の運用では、未導入を維持します。[公式のスキル説明](https://learn.chatgpt.com/docs/build-skills)も参照してください。

導入した環境での明示的な依頼例:

```text
$secure-development-review を使い、今回の変更のセキュリティレビューをしてください。
対象: このPRの差分と、必要な呼出元・共通処理・設定。
期待動作: 利用者は所属テナントのレポートだけを取得できます。
指摘は箇所・証拠・成立条件・影響を示し、重要な不足は保留してください。
コード実行、追加導入、外部送信は行わないでください。
```

指摘の出力例（説明用。新しい検証ケースではありません）:

```text
問題: キャッシュヒット時に所有者確認を経由せず返却しています。
根拠: 取得経路と共有キーの実装。非所有者も同じキーを指定できます。
影響: 非公開データを別利用者へ返す経路があります。
修正方向: 返却前の認可を全経路で強制してください。
範囲: 提供された取得経路のみ。未提供の実効設定は確認していません。
```

利用後に不要になった場合は、自分が配置した対象フォルダと既存変更の有無を確認し、その配置だけを取り除きます。プロジェクトの他のスキルや設定を変更する必要はありません。導入の挙動自体を今回実機で検証したわけではありません。
