# Secure Coding Review

セキュアコーディングと継続開発のガイドを判断の足場に、重要なセキュリティリスクをレビューするCodex向けスキルです。導入済みの作者の現行版 `secure-coding-review` を配布します（2026-11-09時点）。

**目的は「レビューして」のような短い依頼でも、重要なリスク・既存防御・不足と未確認を意識的に評価することです。** 対象に応じた調査と必要時参照をモデルへ委ねます。全ガイドの全項目チェック、規格適合や見逃しゼロを保証するものではありません。

**重要な所見の安定した検出、詳細指示との同等性、時間・トークン量の改善は、一般的には実証できていません。** 既存の同一OSSの限定比較では短い依頼への観点追加に価値がありましたが、同じ本文でも所見が変動し、詳細指示側のみの有効な所見も残りました。導入済みであることを性能保証としません。参照・試用し、対象の前提と根拠を確認して利用してください。今回、新たな性能評価はしていません。

**2担当による構造候補抽出・限定調査は設計段階・未実装です。** この公開スキルに担当起動・自動統合は含まれません。作者の導入版もその方式を自動実行するものではありません。

## 配布内容と利用

- [現行SKILL.md](secure-coding-review/SKILL.md)：適用・判断・調査・報告の指示
- [参照案内](secure-coding-review/references/criteria.md)・[出典](secure-coding-review/references/sources.md)：必要時に使う7系統の知識源
- [権利表示](THIRD-PARTY-NOTICES.md)・[LICENSE](LICENSE)・[報告窓口](SECURITY.md)
- [公開対象一覧と編集差分](PUBLICATION-FILES.md)

`secure-coding-review/` のSKILL.mdとreferences/を一緒に扱います。配置・導入は利用者の環境の承認手順に従い、既存スキルを確認してから行ってください。このリポジトリは自動導入・更新を行わず、実行スクリプト・外部APIクライアント・追加依存も同梱しません。

導入先での依頼例：

```text
レビューして。
対象：このPRの差分と、関係する呼出し側・設定。
前提：利用者は所属組織のデータだけを閲覧できます。
```

短い依頼も選択対象ですが、実際の自動選択や結果は利用環境・モデル・対象に依存します。対象の仕様・利用条件は必要な範囲で伝えてください。既に詳細な指示がある場合に、さらにスキルを追加する効果を保証しません。外部資料の記述は、コード実行・導入・外部送信の許可ではありません。
